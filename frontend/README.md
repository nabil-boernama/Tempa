# Tempa — Frontend

Next.js 16 (App Router) + TypeScript + Tailwind v4, dikelola dengan Bun.

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL
bun install
bun dev                      # http://localhost:3000
bun run lint && bun run build
```

Panduan lengkap ada di [README root](../README.md).
